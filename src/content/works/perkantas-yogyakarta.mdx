## Project Snapshot and Contribution

Perkantas Yogyakarta is a community web platform supporting Christian discipleship activities for students, alumni, and medical professionals.

**My contribution:** Frontend development for the initial 2023 build, followed by maintenance, API migration work, and system stabilization in March–June 2026. Database and backend architecture were outside my ownership.


## Product Challenge

The platform was already in use. I needed to fix existing issues and update the frontend without disrupting everyday community tasks.

## Reflection

This was my first freelance project, and I continued maintaining it after launch. Returning in 2026 meant revisiting earlier decisions, discussing changes with the client, and fixing existing issues before moving on to the migration.

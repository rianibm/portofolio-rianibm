## A little context

Five people, 72 hours, and an anonymous Q&A app to build. That was Spillr, our project for ICP Hackathon Indonesia 2025. We finished a working MVP and took second place in the Internet Identity category.

**My part:** Responsive frontend implementation with React and Tailwind CSS, collaborating with the blockchain backend team.


## What needed attention

Posting a question or reply could take time while the backend processed it. The interface needed to show whether an action was still running or had failed.

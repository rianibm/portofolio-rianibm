## Project Snapshot and Contribution

Indopaket Affiliator Web is a separate affiliate product within the Indopaket ecosystem. It helps affiliates set up an account, manage a referral code, and review earnings.

**My contribution:** UI design and frontend implementation using React, Vite, and Tailwind CSS.

**Status:** Launch planned for late September 2026 alongside the separate mobile app; post-launch results are not yet available.

Some workflows and implementation details have been simplified to protect operational confidentiality.


## Product Challenge

Affiliates need to know what is left to complete in their profile and whether their commission has been paid.

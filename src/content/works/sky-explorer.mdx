## A little context

Sky Explorer is a flight-booking application built as a bootcamp final project.

**My part:** Frontend implementation in a two-person frontend team, including multi-step forms, state management, and responsive interfaces.

**Status:** Original React version completed; a planned Next.js iteration is paused.


## What needed attention

Passengers should be able to go back and change a booking detail without re-entering the rest of the form.

## Implementation Focus

Reusable components, code splitting, and lazy loading supported the multi-step experience. Validation and feedback were handled consistently across search, passenger, and confirmation screens.


## What I built

We completed the responsive booking flow for the bootcamp final project. It was a project build, not a commercial booking service.


## What stayed with me

In our two-person frontend team, we had to agree on where booking data lived and how each step used it. Keeping earlier form entries available was a central part of that work.
